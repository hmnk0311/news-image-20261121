# The World in One Page — Saturday, November 21, 2026

A one-image summary of the world's news of **Saturday, 21 November 2026**,
drawn as a newspaper front page: Russia's barrage hits Kyiv's bridges as
missiles cross into Poland, COP31 deadlocked in overtime in Antalya,
Saudi air defences stop missiles aimed at Riyadh, a claim that AI helped
prove the Riemann hypothesis, and Trump says the U.S., China and Russia
stand together against the ICC after the Shenzhen summit.

This repository is an entry in the make.fun competition
[Sum up 21 November's world news in one image](https://make.fun/c/news-image-20261121).

## How it runs

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `/output/entry.png`. It runs twice in the grader's
sandbox and writes identical bytes both times. Locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
